# legalWebsite

Este proyecto fue inicializado con la plantilla **LandingFactory**.

## Flujo rápido

1. Coloca tus capturas de referencia en `references/` (por ejemplo `references/desktop.png` y `references/mobile.png`).
2. Si tienes imágenes, logos o fuentes originales, colócalos en `assets/`.
3. Abre esta carpeta en **T3 Code** con **Gemini 4 Hydrogen** seleccionado.
4. Ejecuta `/build-landing` (puedes añadir instrucciones extra tras el comando).
5. Revisa los entregables generados en `docs/design/` y las capturas reales en `docs/design/captures/`.

Para auditar un proyecto ya implementado sin reconstruir desde cero, usa `/review-landing`.
